# ui icons

`ex_*` images are copied from exteria `resources/icons/symbol_*`, except `ex_home` and `ex_retry`, which come from exteraless `TMessagesProj/src/main/res`. the home icon is `filter_home.png`; retry is `msg_retry.webp` converted to png at the matching pixel densities. icons are tinted at runtime. the up and left chevrons rotate the corresponding down and right assets.
